Methodology & limitations

Research workflow

1. Start with a predefined list of 100 applications across 10 categories.

2. Search for developer documentation, API references, authentication guidance and MCP resources.

3. Fetch pages and extract findings from page text. Search snippets alone are not treated as proof.

4. Match application names and aliases against the Composio toolkit catalogue as a separate coverage signal.

5. Store per-application results, evidence URLs, fetch errors and fields requiring human review.

6. Manually verify selected findings against official documentation and record verdicts.

Interpretation safeguards

Unknown means insufficient evidence was collected. A failed fetch is not evidence that an API does not exist. A Composio match is not proof of free or self-serve API access. Community MCP servers are distinguished from official vendor MCP support.

Buildability is classified as Easy, Difficult, Blocked or Unknown using the available evidence. It is a research heuristic, not a technical implementation test.
